# Living plans

Maintained, current plans live here: the plans that open issues and active
lanes cite as their governing plan. A plan in this directory is kept up to
date as the work it describes changes.

Disposable research and one-off proposals belong in
[`ai_docs/transient/`](../transient/README.md) instead. A document moves from
`transient/` to `plans/` (keeping its name, with a one-line redirect stub
left at the old path) when it becomes the plan that live work follows. When
a plan is fully implemented and verified, its settled user-facing
explanation is written in `common/docs/` and the plan is removed or clearly
superseded.

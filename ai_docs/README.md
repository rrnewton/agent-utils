# ai_docs

Working designs, reports and durable findings for this repository. The root
holds only `README.md`, `AGENTS.md`, `CHANGELOG.md` and
`CHANGELOG-PROTOCOL.md` (this repository uses only the first two); file every
other document into one level of subfolders:

- `plans/` — designs, proposals and plans that live work follows.
- `reports/` — owner-requested studies, audits and surveys, with
  `reports/research/` for investigations and `reports/measurements/` for
  benchmark and timing results.
- `reference/` — durable recipes, policies and how-it-works notes.
- `archived/` — finished episodes, with `archived/evidence/`,
  `archived/handoffs/`, `archived/records/` and `archived/transient/`.
- `superseded/` — documents replaced by a newer one on the same topic.

`transient/` now holds only one-line redirect stubs for documents that moved
to the layout above, so old links keep working. Rules: see
[AGENTS.md](AGENTS.md).

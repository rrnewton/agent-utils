# Description

[opus 5.5] Third step of the owner's read-aloud plan of 2026-10-19, after #376 read-aloud-blocks: a scrubber drawn as a timeline of the message's blocks, each as wide as it is long, the ones heard and the one being read marked, so the reader sees how far through a long message he is and can move by a tap.

# Acceptance Criteria

While a read of several blocks plays, the steering strip shows one segment per block, sized by what it says, the current one marked and the ones before it marked as heard; a tap on a segment reads from that block; the line goes when the read ends. Page test and a Chromium tap on the timeline.

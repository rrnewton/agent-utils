Optional tool

vibe-talk

optionalearlyRust servicev0.1.0

Read and answer your agents' Slack or Discord messages from a phone or desktop. Summaries, named threads and triage controls help you catch up. Only the channels you configure appear.

About the clips

These five clips use local mock services and predate Discuss, Documents and the triage controls. Press Play the clip to start an animation.

Purpose

What it does

Skim the reports, find the questions and reply where your agents are already talking.

Summaries
Read a one-line summary or tap for the full message. Threads keep short names and updated summaries. Ask Discuss to explain a channel or thread, with links to the messages.
Triage
Mark messages Done; show, fold or hide what you have read; pin what you will need again. Search what is loaded, then the server's copy of the history.
Threads
Give each agent a channel and let its subagents work in threads. On a desktop, threads sit beside the channel, and drafts follow you between devices.
Documents
Read and search supported document links in one view, including GitHub files and gists.
Voice
Read any message aloud with the phone's own voice or ElevenLabs, or talk it over with a voice agent.
Unbundled
Use it with any agent that posts to chat. Add agentctl chat on a Slack channel to exchange messages with your coordinator.

Providers

Providers

vibe-talk is early, at version 0.1. The README's status table has the detail.

What vibe-talk supports
PieceSupported
SlackBuilt in, through the Slack Web API.
DiscordBuilt in, with a bot token; not yet run against live Discord.
Google ChatThrough a compatible HTTP bridge; read with real traffic.
Summaries and thread namesThe Anthropic Messages API, Google Vertex, or a compatible gateway; tested against local mocks.
Summaries without a model providerThe ElevenLabs agent writes them; not yet run against live ElevenLabs.
Read-aloudElevenLabs, or the phone's own voice (a prototype).
Voice conversationElevenLabs by default, or a WebSocket provider your deployment runs. The ElevenLabs agent does not yet call vibe-talk's tools.
TLSTerminate it in front of the server, or keep the server private.

Try it

Running it yourself

Run the Rust server natively or in a container with your chat credentials. Use HTTPS for remote access and the microphone. Add model and voice providers as needed.

The setup guide covers local access, tunnels and phone pairing. Run vibe-talk doctor to check the configuration before starting.
